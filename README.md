# The Binding of dodo

一个致敬《以撒的结合》(The Binding of Isaac) 的肉鸽地牢网页游戏。俯视角，操控 dodo 在随机生成的地下室中探索，用眼泪消灭敌人，拾取道具变强，逐层击败 Boss，打穿 12 层地牢。

所有图形素材（角色、敌人、道具、房间）都是 Canvas 代码画出来的，没有一张图片文件。原生 ES2020 加普通 `<script>` 标签，不用构建，也没有 npm 依赖。

## 运行

任选其一：

```bash
# 方式一：直接用浏览器打开（不需要服务器）
open index.html

# 方式二：本地服务器
python3 -m http.server 8137
# 然后访问 http://localhost:8137/
```

## 操作

| 平台 | 移动 | 射击 | 暂停 |
| --- | --- | --- | --- |
| 桌面端 | WASD | 方向键 ↑↓←→（四向射击） | P 或 Esc |
| 移动端 | 左侧虚拟摇杆 | 右侧四向射击按钮 | 点击暂停界面继续 |

开始 / 重新开始：Enter 或点击屏幕。标题界面用 ←/→（或 A/D）切换角色，也可以直接点击头像；按 S 可输入自定义种子（手动种子局不上排行榜、不计解锁）。

**暂停**：按 P（或 Esc）暂停，暂停界面显示六维属性、当前生效的眼泪效果与已拾取道具；切到别的窗口/标签页会自动暂停，回来后需要自己按 P 继续。暂停期间敌人、弹幕与存活计时全部冻结，按住的按键会被释放，回来不会漂移。

**开发者模式**：按 `` ` `` 开关（右下角显示 DEV）。开启后按 `]` / `[` 在 89 件道具间前后走，每换一件都会把角色重置成初始属性再只装这一件，方便逐个单独试效果；此模式下角色免疫伤害。按 P 看暂停面板可读到这件道具改了哪些属性。

## 玩法

- **地牢**：12 层，每层随机生成 5-10 个普通房间 + 1 个 Boss 房（小地图红点）+ 1 个宝藏房（小地图金块），另有商店 / 诅咒房 / 挑战房 / 秘密房 / 献祭房（45%）等特殊房。进入有敌人的房间时门会关闭，清空敌人后开门。八个视觉章节（BASEMENT / CAVES / DEPTHS / WOMB / SHEOL / CATHEDRAL / THE CHEST / DARK ROOM）各有配色。
- **种子系统**：每局生成 8 位种子（暂停面板可见），标题界面按 S 输入任意文字作种子。同种子 = 同楼层布局、同房型、同诅咒、同道具刷法。
- **道具分池**：89 件道具分宝箱池 / 商店池 / 恶魔池，宝藏房、商店首格、恶魔交易各抽各的池；35% 的宝藏房是「二选一」：两件道具拿一件、另一件消失。
- **恶魔交易**：击败 Boss 后有概率（无伤翻倍）在 Boss 房旁开出恶魔房，两件恶魔池道具标价 1-2 颗红心上限（红心不够改收 3 颗魂心）。
- **D6 六面骰**：主动道具（空格，2 格充能），重摇本房间所有未拾取道具，且按原池重摇（恶魔交易摇出来还是恶魔池、价格不变）。
- **献祭房**：中央尖刺踩一次扣一颗心，奖励随次数递进（金币 → 魂心 → 道具 → 恶魔池道具），第 7 次后祭坛沉寂。飞行躲不掉献祭尖刺。
- **魂心**：蓝色心，先于红心扣除，上限 6 颗。来源：清房小概率、秘密房、献祭房、恶魔房。
- **转变**：集齐 3 件同系道具触发外观 + 能力质变：羽毛系「羽翼圣者」（圣翼飞行 + 光环 + 射速）、恶魔系「恶魔化身」（尖角红瞳 + 攻击 +2.2）、菌菇系「蘑菇之王」（菌盖 + 生命上限 +2 + 巨泪）。
- **诅咒楼层**：第 2 层起每层 30% 概率带一种诅咒（进层横幅紫字预告）：黑暗（视野只剩身边一圈）、迷失（小地图 / 全图失效）、未知（血条变「?」）。
- **战斗**：发射眼泪攻击，每次发射 dodo 都会眨一下眼。岩石会挡住普通眼泪（幽灵弹可以穿过）。敌人接触或弹幕命中会扣半颗心，受击后有短暂无敌。命中敌人时画面会冻结 2 帧（击杀 4 帧），打击感更实。
- **具现化保护期**：敌人进场时从地面升起 + 淡入 + 收缩光环（小怪 0.55s / Boss 0.9s），期间不动、不攻击、不判接触也不吃伤害——开门瞬间不会白送伤害。
- **难度曲线**：指数增长。小怪血量每层 ×1.22（第 12 层约为第 1 层的 9 倍），第 7 层起再叠一条 ×1.14 的二次曲线（成型 build 也不能一枪清房）；接触伤害随章节 1 → 2 → 3 半心；敌方子弹 1-4 层 0.5 心、5-10 层 1.5 心、11-12 层 2 心，深层还有追踪弹；房间敌人密度随深度加速上升。
- **敌人**：Gaper（追击，看到你后永久加速）、Fly（漂移骚扰）、Spitter（悬停远程吐弹，深层追踪弹）、Hopper（跳跃突进）、Sentry（完全固定，旋转四向十字弹）、Boom Fly（对角弹墙，死亡爆炸波及玩家）、Globin（第一次被杀瘫成一滩后重组复活）、Knight（正面免伤，只能绕背击杀）、Vis（充能后发射持续紫色激光）。
- **Boss**：13 个，每层一个，第 12 层击败层 Boss 后会召出第 13 个最终 Boss。形态与攻击两两不同：Gluttono / Duodeno / Larvato / Chubbler / Osseo / Mortuum / Utero / Sanguino / Infernus / Seraphim / Auricus / Umbra / MEGA dodo。
- **Boss 招式**：招式库共 41 种攻击行为，每招只属于一个 Boss，没有任何两个 Boss 共用同一招，每场 Boss 战都要学一套新躲法。代表招式：Gluttono 散射呕吐 + 跳出画面砸地（地面预警圈）；Duodeno 钻地潜行（土丘预警追人，钻出放射爆弹）；Larvato 俯冲横掠沿途播撒幼虫弹 + 召唤小怪；Chubbler 巨型慢速弹中途炸裂 + 环形弹；Osseo 瞬移 + 骨骼迫击炮（多点预警圈）+ 回旋骨镖；Mortuum 死神激光 + 追魂弹 + 全屏发散式持续激光（多束紫色激光放射、预警后整体旋转扫场，为其专属）；Utero 天降弹雨 + 带安全缺口逐波旋转的收缩环 + 主动脉双螺旋喷血；Sanguino 血色光矛钉住玩家行列 + 血球空中分裂 + 惊惶乱射；Infernus 一波比一波宽的火焰吐息 + 带缺口的滚动火墙 + 近身余烬；Seraphim 光环原地收束 + 天罚光柱 + 羽毛飘散扇；Auricus 旋转弹幕 + 四壁金币挤压 + 宝石悬停齐射；Umbra 半虚体幻影突进 + 蛇形交织弹幕 + 窥视之眼狙击；MEGA dodo 四臂反转风车、蝇卵炸弹（爆开兼孵化）、追踪玩家的持续巨型光束、高空连环轰炸后砸地。
- **Boss 血量**：血量 50% 以下进入狂暴，间隔缩短、弹量增加、激光束数更多。血量曲线：第 1 层保持教学难度（300），第 2 层起大幅抬高并按 ~×1.32/层指数增长（900 → 20300，最终 Boss 40000）；第 2 层起每个 Boss 生成时会把血量卡进「玩家估算 DPS」的战时走廊：至少 30 秒、至多约 40+4×层数 秒，低配 build 不会陷入无穷磨血，叠满输出也无法秒杀；最终 Boss 没有上限、保底 60 秒，且会多技能同时施放（含全屏「天启」预警轰炸）。后期接触伤害最高 2 颗心。敌方所有激光与光晕均为紫色，不与玩家的红色 Brimstone 撞色。
- **道具**：89 件可叠加道具，分「改属性 / 改眼泪效果 / 改外观」，多数兼具。底层机制包括：Brimstone 血腥激光（长按射击键蓄力约 0.5s 自动发射，单发伤害更高；提前松手蓄力流失；喙前有血珠 + 进度环反馈；与多弹道并存，齐射时呈扇形多束）、眼泪爆炸（吐根糖浆会炸到自己）、落地分裂、弹墙、中毒、冰冻减速、幽灵弹（穿石）、距离相关伤害（煤炭越远越痛 / 突眼症近强远弱）、暴击、伤害光环、环绕泪、跟随物、接触伤害、吸血、复活、每房一次的神圣护盾、受伤减免、拾取吸附、飞行（dodo 之翼）等，属性有上下限保护，叠满 89 件也不会数值爆炸。
- **飞行**：拾取「dodo 之翼」后 dodo 长出一对翅膀（羽毛爆发 + 翅膀生长动画），从此悬浮飞行、无视岩石等地面障碍。翅膀按移动/瞄准方向做八方向姿态：背对镜头展开最大、面向镜头收拢、侧向与斜向时前后翼大小不同，行走与悬停各有拍翅节奏。
- **角色动画**：每次发射眼泪（含 Brimstone 激光）dodo 都会眨一下眼。
- **属性**：生命、攻击力、射速、弹速、射程、移速（暂停界面常驻面板）。
- **流程**：击败 Boss 后出现地板门进入下一层，第 12 层最终 Boss 击败即通关。每进入一层（含开局）屏幕中央会短暂显示楼层横幅：地名（如 BASEMENT I）+「第 X 层 / 共 12 层」，约 3 秒后淡出。死亡/通关界面显示本局统计（击杀数、拾取道具数、存活时间）。
- **角色**：3 个可选角色，都沿用 dodo 原形象小改，89 件道具与全部动画通用。dodo（均衡开局）；生气 dodo（低血高攻：2 颗心、攻击 +2.4、移速 +15，怒眉 + 泛红配色，累计击杀 300 只解锁）；暗黑 dodo（魂心角色：2 颗红心 + 3 颗魂心开局，魂心先于红心扣除、满血时吃到的心转为魂心储备（上限 6 颗），暗紫配色 + 光环，通关一次解锁）。未解锁角色在选人界面显示为剪影 + 解锁条件。
- **解锁系统**：6 件强力道具默认锁在道具池之外，达成对应成就后永久入池（进度存浏览器 localStorage）：无伤击败任意 Boss → 王者印记；无伤走完一整层 → 神之首；单局拾取 12 件道具 → 四重羽毛；通关一次 → 玻璃大炮；累计击杀 500 只 → 1UP!；累计死亡 10 次 → 死猫。达成瞬间弹提示，结算纸汇总本局新解锁，标题界面展示未完成的目标；开发者模式的局不计任何解锁进度（与排行榜同规则）。
- **分岔层**：第 4 层与第 8 层击败 Boss 后出现两个地板门：左侧安稳门照常下层；右侧尖刺门进入「危险之路」：下一层敌人血量 ×1.35、每房刷怪 +1、Boss 血量 ×1.2，但宝藏房放两个道具座、Boss 奖励翻倍。走近门口有说明卡，进层横幅标红提示。
- **音效**：全部由 WebAudio 实时合成（无音频文件），涵盖射击、命中、击杀、受伤、拾取、开门、过门、Boss 落地、激光、爆炸、暂停/继续、下层楼梯、死亡与通关旋律等。爆炸为分层合成：高频爆裂 + 低通截止频率坍缩的全频段冲击 + 正弦次低音重击 + 延迟低频余响，听感接近真实爆炸。首次按键/点击后自动启用（浏览器自动播放策略）。

- 稳定性：满屏弹幕帧率、控制台无报错
- 平衡专项：激光蓄力门控与提前松手衰减、Boss 血量走廊（30s DPS 下限 + 随层数放宽的上限）、第 1 层教学血量不受影响、进层楼层横幅、最终 Boss 多技能并行与天启全屏技、恶魔房过路费按防御机制可免且传送免费
