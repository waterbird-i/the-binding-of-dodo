# The Binding of dodo

一个致敬《以撒的结合》(The Binding of Isaac) 的肉鸽地牢网页游戏。俯视角，操控 dodo 在随机生成的地下室中探索，用眼泪消灭敌人，拾取道具变强，逐层击败 Boss，打穿 12 层地牢。

所有图形素材（角色、敌人、道具、房间）均由 Canvas 代码绘制，无任何外部资源与依赖。原生 ES2020 + 普通 `<script>` 标签，无构建、无 npm 依赖。

## 运行

任选其一：

```bash
# 方式一：直接用浏览器打开（不需要服务器）
open index.html

# 方式二：本地服务器
python3 -m http.server 8137
# 然后访问 http://localhost:8137/
```

## 操作

| 平台 | 移动 | 射击 | 暂停 |
| --- | --- | --- | --- |
| 桌面端 | WASD | 方向键 ↑↓←→（四向射击） | P 或 Esc |
| 移动端 | 左侧虚拟摇杆 | 右侧四向射击按钮 | 点击暂停界面继续 |

开始 / 重新开始：Enter 或点击屏幕。

**暂停**：按 P（或 Esc）暂停，暂停界面显示六维属性、当前生效的眼泪效果与已拾取道具；切到别的窗口/标签页会自动暂停，回来后需要自己按 P 继续。暂停期间敌人、弹幕与存活计时全部冻结，按住的按键会被释放，回来不会漂移。

**开发者模式**：按 `` ` `` 开关（右下角显示 DEV）。开启后按 `]` / `[` 在 89 件道具间前后走，每换一件都会把角色重置成初始属性再只装这一件，方便逐个单独试效果；此模式下角色免疫伤害。按 P 看暂停面板可读到这件道具改了哪些属性。

## 玩法

- **地牢**：12 层，每层随机生成 5-10 个普通房间 + 1 个 Boss 房（小地图红点）+ 1 个宝藏房（小地图金块）。进入有敌人的房间时门会关闭，清空敌人后开门。八个视觉章节（BASEMENT / CAVES / DEPTHS / WOMB / SHEOL / CATHEDRAL / THE CHEST / DARK ROOM）各有配色。
- **战斗**：发射眼泪攻击，每次发射 dodo 都会眨一下眼。岩石会挡住普通眼泪（幽灵弹可以穿过）。敌人接触或弹幕命中会扣半颗心，受击后有短暂无敌。命中敌人时画面会冻结 2 帧（击杀 4 帧）以强化打击感。
- **具现化保护期**：敌人进场时从地面升起 + 淡入 + 收缩光环（小怪 0.55s / Boss 0.9s），期间不动、不攻击、不判接触也不吃伤害——开门瞬间不会白送伤害。
- **难度曲线**：指数增长。小怪血量每层 ×1.22（第 12 层约为第 1 层的 9 倍），接触伤害随章节 1 → 2 → 3 半心，第 7 层起弹幕伤害翻倍并出现追踪弹，房间敌人密度随深度加速上升。
- **敌人**：Gaper（追击，看到你后永久加速）、Fly（漂移骚扰）、Spitter（悬停远程吐弹，深层追踪弹）、Hopper（跳跃突进）、Sentry（完全固定，旋转四向十字弹）、Boom Fly（对角弹墙，死亡爆炸波及玩家）、Globin（第一次被杀瘫成一滩后重组复活）、Knight（正面免伤，只能绕背击杀）、Vis（充能后发射持续紫色激光）。
- **Boss**：13 个，每层一个，第 12 层击败层 Boss 后会召出第 13 个最终 Boss。形态与攻击两两不同：Gluttono / Duodeno / Larvato / Chubbler / Osseo / Mortuum / Utero / Sanguino / Infernus / Seraphim / Auricus / Umbra / MEGA dodo。攻击行为库包含跳跃冲击、散射呕吐、跳出画面砸地（地面预警圈）、环形弹、旋转弹幕、蓄力冲撞、召唤小怪、激光（虚线预警后发射）、瞄准三连、旋转十字、弹墙弹、天降弹雨、追踪弹 + 弧线弹齐射，以及第 6 层起的**全屏发散式持续激光**（多束紫色激光从 Boss 放射、预警后整体旋转扫场）；血量 50% 以下进入狂暴，间隔缩短、弹量增加、激光束数更多。血量曲线：第 1 层保持教学难度（300），第 2 层起大幅抬高并按 ~×1.32/层指数增长（900 → 20300，最终 Boss 26000）；此外第 2 层起每个 Boss 生成时会按玩家当前估算 DPS 兜底，保证至少能扛住约 30 秒输出，叠满输出也无法秒杀。后期接触伤害最高 2 颗心。敌方所有激光与光晕均为紫色，不与玩家的红色 Brimstone 撞色。
- **道具**：89 件可叠加道具，分「改属性 / 改眼泪效果 / 改外观」，多数兼具。底层机制包括：Brimstone 血腥激光（长按射击键蓄力约 0.5s 自动发射，单发伤害更高；提前松手蓄力流失；喙前有血珠 + 进度环反馈；与多弹道并存，齐射时呈扇形多束）、眼泪爆炸（吐根糖浆会炸到自己）、落地分裂、弹墙、中毒、冰冻减速、幽灵弹（穿石）、距离相关伤害（煤炭越远越痛 / 突眼症近强远弱）、暴击、伤害光环、环绕泪、跟随物、接触伤害、吸血、复活、每房一次的神圣护盾、受伤减免、拾取吸附、飞行（dodo 之翼）等，属性有上下限保护，叠满 89 件也不会数值爆炸。
- **飞行**：拾取「dodo 之翼」后 dodo 长出一对翅膀（羽毛爆发 + 翅膀生长动画），从此悬浮飞行、无视岩石等地面障碍。翅膀按移动/瞄准方向做八方向姿态：背对镜头展开最大、面向镜头收拢、侧向与斜向时前后翼大小不同，行走与悬停各有拍翅节奏。
- **角色动画**：每次发射眼泪（含 Brimstone 激光）dodo 都会眨一下眼。
- **属性**：生命、攻击力、射速、弹速、射程、移速（暂停界面常驻面板）。
- **流程**：击败 Boss 后出现地板门进入下一层，第 12 层最终 Boss 击败即通关。每进入一层（含开局）屏幕中央会短暂显示楼层横幅：地名（如 BASEMENT I）+「第 X 层 / 共 12 层」，约 3 秒后淡出。死亡/通关界面显示本局统计（击杀数、拾取道具数、存活时间）。
- **音效**：全部由 WebAudio 实时合成（无音频文件），涵盖射击、命中、击杀、受伤、拾取、开门、过门、Boss 落地、激光、爆炸、暂停/继续、下层楼梯、死亡与通关旋律等。爆炸为分层合成：高频爆裂 + 低通截止频率坍缩的全频段冲击 + 正弦次低音重击 + 延迟低频余响，听感接近真实爆炸。首次按键/点击后自动启用（浏览器自动播放策略）。

## 自动化测试

```bash
node test/playtest.cjs            # 无头跑全部断言
node test/playtest.cjs --headed   # 打开浏览器观察
```

用 Playwright 以 `file://` 打开页面、发真实键盘事件，再对活的游戏状态做断言：交付形态（无 module / 无 npm）、启动与移动射击、暂停与自动暂停、开发者模式（`` ` `` 开关 + `[`/`]` 换道具 + 免伤）、12 层结构与配色、13 Boss × 全部攻击各模拟 420 帧（含全屏扫场激光与追踪弹）、89 件道具的图标绘制与效果叠加、新机制专项（指数难度曲线、具现化保护期、单敌人命中切帧、激光 × 多弹道、紫色敌方激光、护盾/减伤/自爆/分裂/距离伤害/幽灵弹、骑士正面格挡、Globin 重组、Boom Fly 自爆、Vis 激光、追踪弹与弧线弹、刷怪池）、眨眼与飞行专项（射击触发眨眼、分层爆炸音效、飞行无视岩石、拾取羽毛爆发、翅膀八方向绘制）、12 层 × 25 次地牢生成合法性（连通性/双向门/岩石不堵门）、完整 12 层通关流程、死亡与重开、满屏弹幕帧率与控制台无报错，以及新平衡专项（激光蓄力门控与提前松手衰减、Boss 30s DPS 血量下限、第 1 层教学血量不受影响、进层楼层横幅）。当前 146 / 146 通过。

测试脚本会复用全局安装的 `@playwright/cli` 自带的 playwright，项目本身仍然零依赖。

## 项目结构

```
index.html      入口页面 + 移动端触控 UI
style.css       布局与虚拟摇杆样式
js/utils.js     数学工具 / 常量 / 种子随机
js/audio.js     WebAudio 合成音效
js/sprites.js   全部 Canvas 绘制（房间、dodo、敌人、道具图标、HUD）
js/items.js     89 件道具定义与效果
js/dungeon.js   随机地牢生成 + 小地图
js/entities.js  玩家 / 眼泪 / 激光 / 环绕泪 / 跟随物 / 敌人 / 碰撞
js/bosses.js    13 个 Boss 定义、攻击行为库与 Boss 绘制
js/game.js      主循环 / 输入 / 暂停 / 状态机 / 界面
test/playtest.cjs  Playwright 自动化验收
```
